# 📚 Mi Librería

Una biblioteca digital interactiva desarrollada con HTML, CSS y JavaScript que permite explorar mi colección personal de libros a través de una estantería virtual.

## 🌐 Demo

🔗 https://peran25.github.io/Mi-Libreria/

## ✨ Características

- Visualización de libros mediante sus portadas.
- Estantería interactiva con navegación horizontal.
- Consulta de información de cada libro.
- Diseño inspirado en una biblioteca física.
- Interfaz intuitiva y atractiva.
- Publicación online mediante GitHub Pages.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub
- GitHub Pages

## 📖 Contenido

La biblioteca incluye libros de diferentes temáticas:

- Desarrollo personal
- Filosofía
- Historia
- Novela
- Biografías y memorias
- Crecimiento profesional

## 🎯 Objetivo del proyecto

El objetivo de este proyecto es crear una biblioteca personal digital donde poder organizar, visualizar y consultar mi colección de libros de forma atractiva e interactiva.

Además, este proyecto sirve como práctica de desarrollo web utilizando HTML, CSS y JavaScript, permitiendo aplicar conceptos de diseño, estructura y programación en una aplicación real.
